# Changelog

This project uses semantic versioning for the Python package. Public result schemas
have a separate version; RecourseResult and ValidationReport remain 2.0.0.

## Unreleased - post-audit remediation

- Reuse one fresh deterministic feature/coupling lift per objective evaluation for risk and
  feasibility gradients. Search settings, candidate construction and public schemas are unchanged.
- Add objective/gradient regressions for actual scaled coupling, observed residuals, omitted
  dependent channels, nonlinear teachers, repeated backward passes and invalid outputs.
- Replace the paper outline with a full research draft, verified references, complete measured
  tables and a portable deterministic PDF build from reviewed report data. Add an editable
  research presentation. Submission, peer review and physical benefits remain unestablished.
- Add a preregistered serial measurement runner with exact historical workloads, complete
  outcome/timing retention, guarded resume and engine-bootstrap intervals. Runtime budget
  success requires the completed measurements, not the implementation or development profile.

## Unreleased — Phase 11 audit corrections

- CLI evaluation reports use the same engine-bootstrap definitions as reproduction, expose
  both Tier 2 denominators, target shortfalls and per-query stage uncertainty, and label the
  evidence as statistical/proxy checks. Missing timing evidence remains explicitly unavailable.
- Publication metadata, figure labels and budget diagnoses derive from the measured input;
  visible study tables include observation counts and denominators. Historical results are preserved.
- Historical Phase 4 target/evidence annotations have a prominent erratum.
- Legacy per-query evaluation reports and durable reproduction checkpoints retain the
  validation report's attained evidence level. Historical unlabeled records remain identifiable.
- Unsupported gradient operations raise TypeError as a capability mismatch, replacing
  NotImplementedError guards; implemented predictor/search paths and public schemas are unchanged.

## 0.2.0 — 2026-10-27

- Installable runtime dependencies and optional API, dashboard and baseline extras.
- Portable workspace initialization and dashboard entrypoint, MIT license and citation.
- One-command registered reproduction with durable query records, engine-bootstrap metrics,
  complete manifests and source identity preserved through wheel/sdist builds.
- Verified non-root Docker API/dashboard, README-only clean installation, real demo captures,
  buildable mathematical/API documentation and measured publication tables.
- Includes Phases 7–9: full measured evaluation, operator dashboard, systematic hardening,
  typed failures, trusted artifact boundaries and numerical regression protection.
- Historical experiment source hashes and results remain unchanged. Consult their
  recorded source and dependency manifest rather than treating this release as a rerun.

## 0.1.0 — initial development package

- Data preparation, calibrated predictors, constrained recourse, validation and API/CLI.
- Runtime dependencies were managed in development groups; wheel metadata did not
  install them. The root VERSION file was scaffold metadata and is unified in 0.2.0.

Third-party dependencies and NASA data retain their own licenses and terms; the MIT
license applies to project code. No release upload or archival DOI is claimed.
