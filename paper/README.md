# Research manuscript

The complete editable draft is [manuscript.md](manuscript.md). The generated
[appendix](appendix.md) covers all 24 headline strata, target gaps, historical latency and
predictive/calibration/coupling diagnostics. This is a research draft, not a submission or
peer-reviewed publication. Author identities, affiliations and venue selection remain with
the project owners. No identity is invented.

Build from a clean source checkout using Python 3.11+ and the pinned authoring dependency:

```powershell
python -m pip install -r paper/requirements.txt
python scripts/build_manuscript.py --publication-data paper/evidence.json
```

The output is `output/pdf/prescriptxai-research-draft.pdf`. The reviewed `evidence.json` is
publication report data: aggregated metrics, confidence intervals, provenance and diagnostics.
It contains no raw telemetry, serialized fitted models or model weights. Original source-file
hashes and historical run/config identities remain recorded. No training, refitting or new
experiment is required to typeset the paper.

For an owner-side rebuild directly from the preserved original result files, omit
`--publication-data`. That reads
`artifacts/experiments/phase7-20261020T102540Z/{summary.json,model_metadata.json}` and
`artifacts/phase7-models/index.json`. Generated data and fitted artifacts remain ignored.
The PDF is deterministic for identical text, data and builder inputs.

The [results table](results.md) is separately generated by `scripts/docs_results.py`.
The full [study report](../docs/phase7_changes.md) retains baselines, ablations, the constraint
ladder and K sensitivity, which are separate from headline populations. All measurements
retain their historical source. Maximum evidence is E3 under documented proxy assumptions.
Real-machine benefit and RUL extension remain unestablished.
