Run two separate sessions of about 10 minutes with people who have never seen PrescriptXAI. Use only initials or a participant code in the notes. Local Chromium checks already exercised the FD001 demonstration workflow. Record human observations separately from those checks.

## Facilitator preparation

1. Open the live dashboard in normal mode, or Demo if that is the available workflow. Record the mode and limits label. Use a recorded case with a current prescription and follow-up controls so all four tasks are available. Use the same case for both sessions.
2. Use a laptop with a normal browser window for Session 1. Use a phone for Session 2 if possible. Note the device, viewport, browser and dashboard version. Start each participant with a fresh session at the same recorded baseline and wait for it to settle.
3. Keep this sheet and a stopwatch handy. Keep the mockup screenshots and facilitator notes out of the participant's view.
4. During Task B, keep the participant's edited state visible long enough to hear what changed. Before Task C, if needed, say “I’ll reset the starting state,” then restore the recorded baseline and wait for the prescription. Do this between tasks, with the timer paused, and note the reset. Use the same reset rule in both sessions. Give no navigation hints. Have participants preview Task D without saving a follow-up.

## Invitation

> Hi, could you give me 10 minutes? I'm testing a dashboard for my project. I'm checking whether the page is clear, not whether you're good at it. There are no wrong answers, and I won't help while you use it. You can stop any time.

## Session script

### 1. Ten-second look

Show the page for 10 seconds, then hide it. Ask “In your own words, what is this page for?” Record the answer verbatim.

### 2. Two minutes of free use

Say “Use the page for two minutes however you like. Please think out loud.” Stay quiet. Record actions, pauses longer than three seconds, and any questions. If asked for help, say “What would you try?” Record any help given separately from independent success.

### 3. Four tasks

Read one prompt at a time. Start the timer after reading it. Record whether the person completed it without help, whether help was needed, and the elapsed time. Mark a task incomplete if they move on without finishing.

| Task | Prompt |
| --- | --- |
| A | “Find how risky this engine is right now.” |
| B | “Change one of the settings and tell me what happens to the risk.” |
| C | “Find what the page recommends, and say whether it passed its checks.” |
| D | “Say the operator only followed half of the advice. Show me what happens.” |

### 4. Debrief

- “What was the most confusing part?”
- “Was there a word you didn't understand?”
- “What did you expect to see that wasn't there?”
- “How would you explain this page to a friend?”
- “On a scale of 1 (very confusing) to 5 (very clear), how clear was it?”
