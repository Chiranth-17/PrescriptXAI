## Decisions, limitations and running

No training imports or fitting occur in the runtime UI. Required missing coupling and invalid
artifacts fail closed; credentials stay in environment; cached content identities use the actual
selected artifact bytes. Restart Streamlit after package source updates because development
hot reload may retain an older cached facade class; a cold launch is the supported update path.
The final cold browser process was verified. Run `mingw32-make dashboard`; full gate uses
`mingw32-make all-checks`. API mode uses the same chosen profile and library semantics.

Historical optimization/total target misses remain in `phase7_changes.md`. Passing UI software
checks does not remove those gaps. E3 is conditional on telemetry-proxy/bounds/rates/K assumptions;
there is no validated simulator, physical safety proof or RUL-extension claim. After the closure
commit and phase8-closed tag, proceed immediately to the complete authorized Phase9 prompt.
