# Post-audit remediation

Authorized by the user's request to try to fix the Phase 11 exceptions. The completed audit
at `phase11-closed` remains historical evidence; it is not rewritten or backdated. This work
does not invent another numbered phase or a missing Part B table.

## Work that can be completed locally

1. Measure the current implementation on the unchanged real development workload before
   attributing historical latency gaps to current code. Profile outside measured calls.
   Implement only justified computation reuse; compare values, gradients, true-model outcomes
   and all independent validation tiers. Keep historical timings and scientific settings.
2. After development work and the full software gate, commit the final measurement protocol
   and implementation, then run the complete isolated serial latency workload. Do not mix
   tests, training, artifact rendering or heavy audits with that stage. Record per-query
   outcomes, all timings/outliers, effective settings, engine-bootstrap CIs and actual gaps.
3. Author a complete research manuscript with verified primary references, buildable source,
   compiled PDF and all 24 headline strata. A draft is not submission or peer review.
4. Author an editable presentation covering the actual method, measured results and limits,
   demo, SDG motivation and both defense answers. Render and independently inspect every slide.
5. Prepare a portable public-source release candidate, manifest and credential/history review.
   Resolve actual account/repository access only when publication is concrete and reviewable;
   do not guess an owner or publish to an invented remote.
6. Maintain a follow-up map of every original exception, current evidence and residual need.

## Scientific constraints

All historical configurations, models, thresholds, bounds, rates, populations and raw records
remain unchanged. Computation reuse may not erase observed coupling residuals or change the
search settings to pass a budget. A new solver/scientific policy requires separate development,
committed preregistration and appropriately separate evaluation evidence.

Static data cannot establish real actuator responses, physical safety, validated dynamics,
causal failure reduction, field SDG/resource/lifespan/disposal/downtime benefits or RUL extension.
Historical once-ever test exposure cannot be undone. These items need new evidence, rather
than a changed label. Finite reference-search failure alone does not certify infeasibility.

## Gates

Root implements; independent agents audit work they did not implement. Run Ruff, strict mypy,
pytest with nondecreasing coverage, strict docs and relevant real workflow checks. Update
PROGRESS and the follow-up report with actual numbers, then commit conventionally. Do not
mark a requirement Done without evidence or claim a target from a development profile.
